# 导航质量验证记录

日期：2026-09-21。本轮验证使用本地已有素材、碰撞体和导出的导航地图。
没有重新训练高斯场景、没有运行新的 Isaac Sim 建图、没有修改已发布世界。

## 结论

视频注册成功和基础可达地面检查只能筛掉部分坏输入，不能证明场景适合 VLN 训练。
现有 8 个生成/重建场景仍未通过项目的完整 VLN 标准；人工参考场景通过。

本轮修复了一个可复现的地图稳定性问题：相同碰撞体多次建图时，随机表面采样既会漏采
完整地板，也会改变栅格边界和出生点对应的格子。修复后地板由实际三角面在格子中心的
高度决定，边界由网格顶点决定；头顶净空采样使用局部固定随机种子。
真实网格空洞保持为空，不向未观测空间补地板。净空仍是采样近似，未改成完整碰撞证明。

## 相同碰撞体重复三次

下表由相同变换、尺度、出生点和碰撞体离线运行得到；单位为平方米。
完整输出位于 `.artifacts/navigation-validation/walkable-before.json` 和 `walkable-after.json`。

| 输入 | 修复前可达面积范围 | 修复后每次可达面积 | PNG 与元数据是否可重复 |
| --- | ---: | ---: | --- |
| 4×4 米完整地板 | 13.75–13.79 | 13.97 | 从不一致变为完全一致 |
| Family | 0.14–0.20 | 0.22 | 从不一致变为完全一致 |
| 多视角会议室 | 72.07–75.94 | 43.60 | 从不一致变为完全一致 |

会议室面积下降不能表述为导航质量提高。旧方法把只被三角面边缘擦到的格子也计作地板；
新方法要求格子中心有实际表面支撑，结果更保守。Family 仍几乎没有连续可达地面，
不能靠稳定地图或增加训练步数宣称已经修复其几何。Family 原始素材的接触表显示它是
围绕室外雕像拍摄的序列，不能代替多房间导航场景的验收输入。

这两个真实碰撞体每次建图由约 0.07–0.17 秒变为约 0.38–0.43 秒。精确地板计算增加少量
CPU 开销；上方遮挡仍使用固定采样，细小障碍仍需仿真碰撞验收。包含新增回归的全部 CI CPU
测试本轮为 **196 passed**；批量验收在失败场景返回 1、人工参考场景返回 0、缺失输入返回 1。

## 后续实验的输入与通过条件

1. 选择或采集一段真实多房间素材：至少两个房间与连接走廊，完整走过门口、转角和主要地面，
   保留连续移动与回程重叠。现有雕像环拍和单会议室素材只作回归样本。
2. 固定同一原始输入、相机高度和训练环境，在独立输出目录比较 Standard 与 Navigation。
   保存时间、注册帧、渲染对比、碰撞体、可达面积，不覆盖原结果。
3. 重新导出并运行 Isaac Sim 建图后，再运行同一份完整 VLN 验收：至少 20 视点、最大连通
   分量比例 ≥90%、覆盖率 ≥90%、绕行 p90 ≥1.2、至少 50 条合格路线；不可评估不能算通过。
4. 几何通过后还需验证视点观测、语义与指令质量，以及实际导航训练效果。当前没有这些证据。
